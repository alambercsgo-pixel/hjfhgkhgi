# Учебный сайт — контрольная работа по HTML и JavaScript

Многостраничный сайт на HTML5 и JavaScript **без CSS**: нет CSS-файлов,
тегов `<style>` и атрибутов `style="…"`. Всё оформление сделано средствами HTML:
заголовки, списки, таблицы, `<hr>`, выделение тегами `<mark>`, `<b>`, `<strong>`,
а в таблицах — HTML-атрибуты `border`, `cellspacing`, `cellpadding`, `bgcolor`,
`background`, `align`, `valign` (как в образце).

Требования: https://github.com/vmarshirov/g06u28/tree/main/task_01

## Запуск

1. Откройте папку `my-site` в VS Code (File → Open Folder).
2. Установите расширение **Live Server** (автор Ritwick Dey), если его нет.
3. Щёлкните правой кнопкой по `index.html` → **Open with Live Server**
   или нажмите **Go Live** в строке состояния внизу.
4. Сайт откроется по адресу вида `http://127.0.0.1:5500/index.html`.

Сайт также открывается двойным щелчком по `index.html` (адрес `file://...`).

## Настройки перед защитой

- **Адрес сервера для форм и задачи.** У трёх форм есть атрибут `data-remote=""`:
  две формы в `form.html` и форма в `task.html`. Пока он пуст, данные проверяются
  и обрабатываются на странице и никуда не отправляются. Чтобы форма после проверки
  отправлялась на сервер (в новой вкладке), впишите его адрес в `data-remote`.
- **Скриншот консоли для `DOM.html`.** Команды подставлены на самой странице
  (раздел «4. Скриншот консоли»). Сохраните скриншот как `image/dom-console.png`
  и уберите комментарий вокруг блока `<figure>` в `DOM.html`.
- **Данные паспорта.** В макете вымышленные данные. Если нужны свои фамилия, имя
  и год рождения, поменяйте соответствующие `<b>` в `passport.html` и `DOM.html`
  (в обоих файлах одинаково). Латиница вычисляется автоматически.
- **Свои шаблоны паспорта.** Шаблоны на `DOM.html` — картинки `image/passport-ru.svg`
  и `image/passport-zagran.svg`. Их можно заменить своими изображениями; тогда в начале
  `scripts/dom.js` нужно поправить размер картинки (`TEMPLATES`) и координаты полей (`LAYOUT`).
- **Номер задачи.** Реализована задача № 1003. Если ваш номер другой, нужно
  поменять условие в `task.html` и функцию `solve()` в `scripts/task.js`.

## Как текст стоит поверх картинки без CSS

На `DOM.html` шаблон паспорта — картинка внутри встроенной SVG-графики (`<image>`),
а каждое поле данных — HTML-абзац `<p>` внутри `<foreignObject>`: это прямоугольник
с координатами `x`, `y`, `width`, `height` (атрибуты SVG, а не CSS). Кнопка меняет
у `<image>` адрес картинки, а у полей — координаты и текст. Абзацы остаются обычными
HTML-элементами, поэтому команда `document.getElementsByTagName('p')[N].childNodes[1].innerText`
читает их, как и раньше.

## Что даёт отказ от CSS

- Валидатор W3C помечает табличные атрибуты (`cellspacing`, `cellpadding`, `bgcolor`,
  `background`, `align`, `valign`, `width`, `height`) как устаревшие: в HTML5 их
  заменил CSS. Браузеры их по-прежнему поддерживают, и без CSS другого способа
  задать фон таблицы и выравнивание нет. Остальная разметка ошибок не содержит.
- Подстраивать размеры под экран без CSS нельзя. Изображения подобраны так,
  чтобы помещаться на телефоне, кроме двух, ширина которых задана заданием:
  таблицы 600 px и большого изображения 600 × 400. На телефоне их нужно
  прокручивать вбок.
