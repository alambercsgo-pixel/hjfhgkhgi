Учебный сайт на HTML и JavaScript

Сайт собран для контрольной работы: на нём показаны основные элементы HTML-страниц — тексты, списки, изображения, таблицы, формы — и работа JavaScript со страницей через DOM.

Разделы сайта

Информационные страницы

  • Информация — рецепт, времена года и текст о смене сезонов; списки, разделители и переходы по закладкам вверх и вниз.
  • Фото — изображения с подписями; миниатюра открывает большое фото в новой вкладке.
  • Таблица — таблица с фоновым изображением, картинками в ячейках и гиперссылками.
  • Формы — форма контактных данных и форма с полями разных типов.

Задания на DOM и JavaScript

  • DOM_JS — шаблон паспорта картинкой с данными поверх неё, переключение на загранпаспорт; считываем фамилию, имя и год рождения из DOM.
  • Кириллица → латиница — по клику на кнопку данные паспорта меняются с кириллицы на латиницу и обратно.
  • Задача — решение алгоритмической задачи: JavaScript проверяет данные и выдаёт ответ.

Как пользоваться сайтом

  1. Выберите раздел в меню вверху страницы. Пункт открытой страницы выделен жёлтым и жирным, пункт под курсором — жёлтым.
  2. Пункт «Закладка: рецепт» сразу открывает нужный раздел информационной страницы.
  3. Логотип в меню всегда возвращает на эту главную страницу.
  4. Ссылки со стрелкой ↗ ведут на внешние сайты и открываются в новой вкладке.

О сайте

Использованы только две технологии, без CSS, библиотек и сборщиков:

  • HTML5 — структура страниц и всё оформление: заголовки, списки, таблицы, выделение тегами <mark> и <b>;
  • JavaScript — выделение пунктов меню и интерактивные задания.
